About Me

Hi, I'm Zarzis, a third-year Computer Science student at AIUB and an aspiring Frontend Developer. I like turning ideas into fast, responsive interfaces that feel simple to use, and I'm always picking up something new along the way.

My Programming Journey

I wrote my first lines of code in 2021 and started with the basics: HTML, CSS and JavaScript. Since then I've moved on to Tailwind CSS, React and Next.js, and learned to work with Git, GitHub and Linux. Studying Computer Science at AIUB keeps my fundamentals strong, while projects like FitLog let me put them into practice.

Work I Enjoy

Frontend work is where I'm happiest: turning a design into clean, responsive layouts, adding small interactions that make a page feel alive, and structuring components so they're easy to reuse. I like problems with a clear, visible result, and I care about clean code and performance as much as looks.

Life Outside Code

Away from the keyboard you'll find me working out, playing guitar or reading self-help books. My love for the gym even shows up in projects like FitLog, while music and books are how I slow down and keep growing.
